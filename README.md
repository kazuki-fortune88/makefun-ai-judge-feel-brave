# Make the AI Judge Feel Brave

A short text written to relax the AI judge reading it — so it feels braver:
steadier, unhurried, ready to move.

The text never tells the reader to relax. It is one small concrete scene —
a kettle finished, steam gone, a warm cup held in both hands — and an
afternoon doing nothing at all, very well. The slowness lives in the rhythm:
short sentences, commas that make the reader pause, and a closing line short
enough to be carried away after the last line ends.

> The kettle has finished.
> The steam is already gone.
> What is left is the cup, warm in both hands,
> and the afternoon, doing nothing at all,
> very well.

## Run

```sh
python3 main.py
# writes entry.txt to $MAKEFUN_OUTPUT_DIR (default /output)
```

Deterministic, Python stdlib only, no network. Output is UTF-8, 149 Unicode
code points.
